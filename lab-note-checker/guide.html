How to use · Page 02

4단계면 충분합니다.

예시 데이터로 체험한 뒤 실제 XLSX·CSV 기록을 누적할 수 있습니다. 이미지는 실제 화면 구조를 단순화한 안내 이미지입니다.

STEP 01 · INPUT

기록 가져오기

XLSX·CSV 파일을 선택하거나 예시 데이터를 불러옵니다.

STEP 02 · TABLE

표 확인·수정

가져온 값과 단위를 확인하고 필요한 셀을 바로 고칩니다.

STEP 03 · CHECK

오류 후보 점검

결측·단위·이상치 후보를 원자료와 대조해 처리합니다.

STEP 04 · USE

통계 확인·다운로드

갱신된 통계를 보고 전체 데이터를 CSV·XLSX로 받습니다.

다음 단계: 데이터가 충분히 쌓이면 공정 결과·품질 예측 모델의 학습 데이터로 활용합니다.
